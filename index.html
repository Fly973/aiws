多目的地智能导航 · 自驾/公交/步行

免费获取密钥（约2分钟）：

  1. 访问 高德开放平台 注册登录
  2. 控制台 → 应用管理 → 创建新应用
  3. 添加 Key → 服务平台务必选「Web端(JS API)」
  4. 复制 JS API Key 填入上方；安全密钥有就填，没有就留空
  5. Key 的「允许访问的域名」添加 localhost 和 127.0.0.1

注意：不要选「Web服务」Key，那个没有安全密钥，也不能用于本应用。

密钥仅保存在本地浏览器，不上传任何服务器。
